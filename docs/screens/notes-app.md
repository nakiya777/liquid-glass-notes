# メモアプリ画面仕様

- 文書種別: 領域別正本（画面）
- ステータス: 現行
- 更新日: 2026-09-14

## 構成

一枚のガラス板を三分割する。板の外周だけが屈折し、内側は塗りの濃さで領域を分ける。

```
┌─ ガラス板（外周で屈折） ───────────────────────┐
│ フォルダ │ メモ一覧 │ エディタ（白い用紙が浮く） │
└────────────────────────────────────────────┘
      └ 下端中央にツールバー、右上に操作パネル
```

| 幅 | 表示 |
|---|---|
| 1080px 超 | 三分割 |
| 860〜1080px | 一覧とエディタ（フォルダは隠す） |
| 620px 未満 | エディタのみ |

## フォルダ欄

- 見出し「フォルダ」と「編集」ボタン
- iCloud 節（開閉可）: すべての iCloud / 利用者フォルダ / 最近削除した項目
- タグ節（開閉可）: 使用中のタグ一覧
- 左下に新規フォルダボタン

| 操作 | 結果 |
|---|---|
| フォルダを押す | 選択を切り替え、そのフォルダの先頭メモを開く |
| フォルダを二度押す | 名称変更（システムフォルダを除く） |
| 「編集」→ 各行の鉛筆／ゴミ箱 | 名称変更／フォルダ削除 |
| フォルダ削除 | 中のメモはゴミ箱へ移す（即時削除しない） |

## メモ一覧

- 見出しは選択中フォルダ名、右に表示オプション（並べ替え、ゴミ箱を空にする）
- 検索欄（タイトル・本文・タグを対象）
- 各行: タイトル、更新日時、本文の抜粋、サムネイル
- 手書きのあるメモはサムネイルにストロークを縮小表示する
- 下端に件数

並び順は ピン留め → 更新日時の降順 を既定とし、作成日時順・タイトル順へ切り替えられる。

## エディタ

- タイトル欄と本文欄（リッチテキスト）
- 本文の上に手書き層を重ねる
- ゴミ箱のメモは編集不可。上部に「元に戻す／完全に削除」の帯を出す

## 下端ツールバー

| 状態 | 内容 |
|---|---|
| 通常 | 取り消し、やり直し、書式(Aa)、チェックリスト、表、画像添付、手書き |
| 手書き中 | ペン／マーカー／鉛筆／消しゴム、色6種、太さ、完了 |

手書きモードは開いたメモに紐づく。別のメモへ切り替えると自動で閉じる。

## 右上の操作パネル

| ボタン | 内容 |
|---|---|
| しずく | ガラスの設定（材質、縁の屈折、OS の透明度設定に従う） |
| 共有 | Markdown をコピー、.md 書き出し、印刷。いずれも端末内で完結する |
| … | ピン留め、タグ編集、ゴミ箱に入れる |
| 作成 | 新規メモ |

## キーボード

| 操作 | 割当 |
|---|---|
| 取り消し | ⌘Z |
| やり直し | ⇧⌘Z |
| 新規メモ | ⌘N |
| ゴミ箱へ | ⌘⌫ |

## 受入条件

1. フォルダ・メモの作成、改名、削除、復元ができる。
2. 検索が タイトル・本文・タグ に効く。
3. 取り消しは直前の一操作だけを戻す。連続した文字入力は 0.7 秒以内なら一塊にまとめる。
4. 再読込後も内容と設定が残る。
5. 画像は 2MB を超えると拒否し、理由を伝える。
