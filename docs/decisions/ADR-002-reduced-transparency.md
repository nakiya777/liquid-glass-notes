# ADR-002 OS の「透明度を下げる」は既定では尊重しない

- ステータス: 採用
- 決定日: 2026-09-14

## 背景

当初は `@media (prefers-reduced-transparency: reduce)` でガラスを不透明化していた。macOS の「透明度を下げる」が有効な環境では、アプリ全体が白い平面になり、本アプリの主題である材質がまったく見えなくなった。

## 決定

OS 設定は自動では適用しない。設定メニューに「OS の透明度設定に従う」を置き、利用者が明示的に選んだ時だけ不透明化する。判定は CSS の media ではなく `useMediaQuery` で読み、`<html data-flat>` を立てて CSS 側へ渡す。

## 判断の根拠

本アプリの目的はガラス材質の実証である。材質を消すと製品として成立しない。一方で設定を無視し続けるのも誤りなので、切替を可視化し、有効時はメニューに「この Mac は『透明度を下げる』が有効です」と表示する。

一般的な業務アプリであればこの決定は逆になる。OS 設定を既定で尊重すべきである。

## 結果

- 既定: ガラスを描く
- 設定で従うと: ぼかしと屈折を止め、塗りを 97% 不透明にする
- `prefers-reduced-motion` と `prefers-contrast` は従来通り無条件で尊重する
