# 製品概要

- 文書種別: 領域別正本（製品）
- ステータス: 現行
- 更新日: 2026-09-14

## 目的

Apple が iPadOS / macOS で採用する Liquid Glass の質感を、Web 標準だけでどこまで再現できるかを実証する。題材として iPad 純正メモアプリ相当の三分割画面を、実際に使えるメモアプリとして実装する。

## 範囲

- 三分割画面（フォルダ／メモ一覧／エディタ）
- フォルダとメモの作成・改名・削除・復元
- リッチテキスト編集、チェックリスト、表、画像添付
- 手書き（ペン・マーカー・鉛筆・消しゴム）
- 検索、並べ替え、タグ、ピン留め
- 取り消し／やり直し
- 端末内保存（localStorage）
- Markdown への書き出し、印刷

## 対象外

- サーバ同期、複数端末間の共有、アカウント
- 共同編集
- 画像の外部保存（添付は data URI で localStorage に入るため 2MB 上限）

## 成功基準

1. 背景画像の構造が板の内側に透けて見え、縁で像が屈折する。
2. 屈折に非対応のブラウザでも、ぼかしガラスとして破綻なく成立する。
3. 背景の明るさに応じて明／暗の材質が自動で切り替わり、文字が読める。
4. メモアプリとして一通りの作成・編集・削除・復元・検索ができる。
5. 再読込後も内容が残る。
